# Crayon Babies sound-effect library (reuse for free)

Made with ViewMax `generate_sound_effect` (5 credits each). Reuse these before generating new ones.
"usable" = the part with sound (trim with `max` in edit.json). "vol" = level that sat well over a -14 LUFS song.

| file | sound | usable | vol |
|---|---|---|---|
| pop.mp3 | soft bubble pop for on-screen words (added automatically by montage.py) | 0.07 s | 0.45 |
| baby_lion_squeak.mp3 | tiny cub tries to roar, cute squeaky mew | 1.0 s | 0.55 |
| kitten_meow.mp3 | one cute surprised meow | 0.85 s | 0.6 |
| lion_cub_roar.mp3 | big proud friendly cub ROAR (not scary) | 1.9 s | 1.0 |
| toddlers_cheer_clap.mp3 | two toddlers "yay!" + clapping + giggles | 2.1 s | 0.75 |
| toddlers_gasp.mp3 | two toddlers gasp "ooh!" in surprise (hooks, "Oh no!") | 0.65 s | 0.8 |
| crayon_scribble.mp3 | crayon scribbling/drawing (quiet file, max -16 dB) | 1.5 s | 2.0 |
| sparkle_chime.mp3 | magic sparkle chime, something lights up | 1.35 s | 0.8 |

When you generate a new effect that could be reused (giggle, gasp, sparkle chime, splash, boing, whoosh,
puppy bark, ...), save it here with a clear name and add a row.
Prompt pattern: `<one sound>, cartoon style, cute, kid-friendly, single short sound, clean, no music, no background noise.`
with `duration_seconds` 0.5-2.5 and `prompt_influence` 0.6.
